
# Capturas incluídas no lançamento público

As capturas desta pasta foram selecionadas para demonstrar o fluxo funcional do Engineering Toolkit sem distribuir código corporativo nem bibliotecas proprietárias.

Arquivos incluídos:

1. `importer-icon.png` — ícone do importador no E3D.
2. `overview-e3d-workspace.png` — ambiente E3D com o contexto de importação selecionado.
3. `empty-preview-state.png` — estado inicial da interface antes da abertura do JSON/PCF.
4. `preview-loaded-pipeline.png` — preview do pipeline com tabela de componentes.
5. `catalog-analysis.png` — análise de catálogo e divergências.
6. `execution-destination.png` — aba de destino e execução.
7. `execution-confirmation.png` — confirmação antes da escrita.
8. `history-diagnostics-grid.png` — histórico em grade.
9. `history-text-log.png` — log textual do plano e avisos.
10. `result-e3d-model.png` — resultado no modelo E3D.
11. `result-e3d-tree-detail.png` — detalhe da árvore de componentes.

Antes de uma publicação definitiva, recomenda-se revisar novamente se algum identificador interno do ambiente deve ser anonimizado.
